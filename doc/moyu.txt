*moyu.txt*                 Read books inside your code window

MOYU.NVIM                                                     *moyu.nvim*

Requires Neovim 0.9+. No Lua plugin dependency. fzf is optional.
Python 3 is required for EPUB/HTML/DOCX/ODT/FB2 and encoding conversion.
PDF uses pdftotext. Kindle formats use Calibre's ebook-convert.

COMMANDS                                                       *moyu-commands*

:Moyu [file]           Search books, or read the specified file in Moyu Mode.
:MoyuToggle            Resume the last book, or exit Moyu Mode.
:MoyuClose             Save progress and close reading.
:MoyuHistory           Search reading history and resume the selected book.
:MoyuBooks             Search configured books and reading history.
:MoyuFloat [file]      Read in a floating window.
:MoyuFloatToggle       Toggle the floating reader.

:MoyuStealth and :MoyuStealthToggle are compatibility aliases.

KEYS                                                           *moyu-keys*

Configure <leader>my in your plugin manager to run :MoyuToggle.
The plugin does not install a global key mapping by itself.

During Moyu Mode:
  <leader>my, Esc, Ctrl-C     Save and exit; restore the original mappings.
  j, Down, Enter, Ctrl-D     Next segment.
  k, Up, Backspace, Ctrl-U   Previous segment.
  F2                        Reading history.
  F3                        Toggle concentrated / spread layout; remember choice.
  <leader>mp                        Pin / unpin the current background code file.
  +, =, keypad +            Increase visible lines by one.
  -, keypad -               Decrease visible lines by one (minimum one).
  Other printable ASCII     Advance every three presses (configurable).

The source buffer is temporarily nonmodifiable. Book text is virtual text;
it is never written into code or undo history. Leaving the window or losing
focus hides reading. Terminal focus reporting depends on the terminal.

CONFIGURATION                                                  *moyu-setup*
>
  require('moyu').setup({
    book_dir = '~/Books/moyu',
    stealth = { lines = 4, keys_per_step = 3, background = true },
    width = 0.65,
    height = 0.7,
    border = 'rounded',
    title = ' 阅读 ',
  })
<
The default library is ~/Books/moyu, separate from the plugin installation.
Create this directory and put your books there. Repository books/ contains
only an optional demonstration text; copy it into your library to try it.
The initial layout is concentrated: up to 4 consecutive comment rows near
the cursor. Press F3 inside Moyu Mode to switch to spread comments across
visible code lines. Spread comments use up to 40 display cells and follow
the code indentation. Small windows and buffers with few code lines show
fewer spread comments without skipping book text.
Use +/= and - to change the desired line count without moving in the book.
This preference survives restarts unless stealth.lines is set explicitly.
The layout choice also survives restarts. Set stealth.layout to 'block' or
'spread' to override the saved startup layout. F3 only has a temporary
buffer-local mapping during Moyu Mode; exit and auto-hide restore the
original mapping. Normal editing and floating reading have no F3 binding
installed by the plugin.

Background code rotates to another file on each next segment, only in Moyu
Mode. Candidates include open code buffers and nearby project source files.
Discovery is bounded to 3 directory levels, 2000 entries and about 40 files,
skipping hidden directories and common dependency/build directories. Unnamed
buffers do not trigger directory scanning. Without another readable code
file, the current background stays. Previous segment, layout/line changes
and attempts to advance past the book's end do not rotate the background.
Exit and auto-hide restore the initial buffer, cursor and viewport. Unsaved
code, original buffer mappings and modifiable settings are preserved; clean
buffers loaded only for rotation are removed. Set stealth.background=false
to disable rotation. Floating reading does not rotate code files.

Press <leader>mp inside Moyu Mode to pin the current background file. Reading keeps
advancing without changing code files; press <leader>mp again to resume rotation on
the next segment. Layout and line-count changes keep the pin. The pin lasts
only for the current session and clears on exit or auto-hide. The temporary
buffer-local <leader>mp mapping restores the original mapping on exit. If rotation
is disabled in configuration, <leader>mp reports that setting without enabling it.

PROGRESS                                                       *moyu-progress*

Every book is identified by its absolute source path. Moyu Mode saves both
the extracted text line and Unicode character offset. Opening that book again
resumes automatically, including after restarting Neovim. History is sorted
by the last reading time. Records are stored under:
  stdpath('data')/moyu/progress.json

Moving or modifying a book can invalidate its old position. PDF positions
refer to extracted text, not printed page numbers. Images, OCR, DRM and
original rich formatting are not handled by the text reader.

API                                                            *moyu-api*

require('moyu').is_active()    Return whether Moyu Mode is active.
require('moyu').status()       Return '鱼' while active, otherwise ''.

User MoyuModeChanged fires on enter/exit with event.data.active and
event.data.buffer. No personal history is included in these events.
